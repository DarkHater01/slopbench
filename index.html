Open-source benchmark · code inflation in LLM agents

🪢 SlopBench

Code benchmarks measure whether a model solves the task. None measure how much code it wastes. Every model solves the same 5 Python tasks inside a sandbox, and the metric only counts runs that pass the tests: inflation = generated LOC ÷ reference LOC.
